Perplexity is an AI answer engine: instead of returning ten blue links, it searches the web in real time and writes a direct, synthesized answer with numbered citations you can click to verify. It occupies a space between a traditional search engine like Google and a chatbot like ChatGPT — you ask a question in natural language and get a sourced response, then keep drilling in with follow-ups.

The citation model is the whole point. Because every claim is footnoted to a source, Perplexity is far more checkable than a chatbot answering from memory, which makes it a favorite for research, fact-finding, and staying current. Pro users can choose the underlying model (GPT, Claude, or Perplexity's in-house Sonar), run deeper multi-step "Pro" searches, and organize work into Spaces.

Perplexity has expanded well beyond search — it offers a Discover feed, a Deep Research mode for longer reports, and Comet, its own AI browser that pushes it into agentic, task-completing territory against Google and OpenAI.

## Key Features

- Real-time web search with numbered, clickable citations
- Conversational follow-up questions that keep context
- Model choice on Pro (GPT, Claude, Sonar)
- Deep Research mode for longer, structured reports
- File and image upload for analysis
- Spaces for organizing and collaborating on research
- Comet AI browser and an API for developers

## Pricing

- **Free**: Standard searches plus a small daily allowance of Pro searches
- **Pro (around $20/month)**: Near-unlimited Pro searches, model selection, file uploads, and Deep Research
- **Enterprise**: Team management, security controls, and internal data connections

## Best For

Researchers, students, journalists, analysts, and anyone who wants fast, cited answers to factual questions and would rather verify sources than trust a chatbot's memory.

## Limitations

Perplexity is a summarizer at heart — it retrieves and condenses sources rather than reasoning from scratch, so for open-ended creative work or deep original analysis a model like Claude or GPT is stronger. It can also over-trust a shaky source, so the citations are there to be checked, not blindly accepted.
