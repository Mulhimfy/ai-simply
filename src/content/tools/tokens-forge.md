Tokens Forge is a commercial OpenAI-compatible API gateway that routes requests to GPT, Claude, Gemini, and pooled model tiers behind a single endpoint. It layers API-key controls, model access scopes, a wallet with usage records, and request-level receipts on top of fallback-aware routing, so developers can switch models without changing code and keep a transparent record of what each call cost. A free AI Stock Researcher for research-only market summaries is bundled in.

## Key Features

- OpenAI-compatible endpoint for GPT, Claude, Gemini, and routed model pools
- API-key controls and per-key model access scopes
- Wallet, usage records, and request-level receipts
- Fallback-aware routing across model tiers
- Transparent, published pricing
- Free AI Stock Researcher for research-only market summaries

## Best For

Developers and teams who want a single OpenAI-compatible gateway across multiple providers, with granular key controls, spend transparency, and automatic fallback between models.
