BrickGPT takes a photograph and works out how to rebuild it as a brick model, producing a parts breakdown and step-by-step assembly instructions. It targets the gap that custom building runs into: deciding which pieces approximate a shape, and in what order to place them so the structure holds together as it goes up.

Custom builders normally solve this with dedicated CAD-style software and a long learning curve. Starting from a photo lowers that barrier considerably, though the output is a proposal rather than an official set — expect to adapt it against the bricks you actually own.

BrickGPT is an independent tool and is not affiliated with or endorsed by the LEGO Group.

## Key Features

- Photo-to-model conversion
- Parts list for planning a build
- Step-by-step assembly instructions
- Aimed at custom, non-official builds

## Best For

Custom brick builders who want a starting plan and parts list from a reference photo instead of designing a model from scratch.
